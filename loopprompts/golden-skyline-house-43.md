# Golden Skyline House 43

## 4 SA3 Loop Prompts

**Shared generation settings:** 128 BPM | 4/4 | 4 bars | 7.500000 seconds | F major.

Set the duration in the generator as well as using the prompt. Tempo, key, isolation and loop joins are targets to check by listening, not guaranteed output properties. These are independently generated parts, not stems extracted from one performance.

### Prompt 1: Uplifting house groove
```text
TrackType: Music, VocalType: Instrumental, 128 BPM, 4/4, F major. Uplifting progressive-house groove with a bright synth melody, picked guitar chords and rounded bass. Firm four-on-the-floor drums hold a steady phrase; clear melodic answers and short ambient tails maintain forward motion. Repeating four-bar loop, steady phrase throughout, clean return to the opening beat.
```

### Prompt 2: Bright synth melody
```text
TrackType: Instrument, 128 BPM, 4/4, F major. Solo supersaw synthesizer repeating a hopeful major-key melody. Short rising notes answer a held upper tone, with clean attacks, gently detuned harmonics and a compact stereo echo. Repeating four-bar loop, steady phrase throughout, clean return to the opening beat.
```

### Prompt 3: Big-room drum groove
```text
TrackType: Instrument, 128 BPM, 4/4. Isolated big-room house drums with a deep four-on-the-floor kick, crisp clap backbeat and bright offbeat hats. Small snare pickups connect the phrase; firm transients and short, controlled decays. Repeating four-bar loop, steady phrase throughout, clean return to the opening beat.
```

### Prompt 4: Rhythmic guitar arpeggio
```text
TrackType: Instrument, 128 BPM, 4/4, F major. Solo clean electric guitar repeating an uplifting major-key arpeggio. Muted lower-string pulses answer chiming upper notes, with light picking detail and a short dotted rhythmic echo that stays behind the phrase. Repeating four-bar loop, steady phrase throughout, clean return to the opening beat.
```
