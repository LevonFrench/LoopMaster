# Loop Packs

50 styles, four loop prompts per style. Names use three descriptive words followed by a two-digit pack number: **X Y Z ##**.

Each sheet begins with four musical or percussion loops. Additional one-shots, fills and transitions appear at the bottom, outside the four loop slots.

## Generation

Use the BPM, key and duration shown in each sheet. Every loop requests four bars in 4/4: duration in seconds is `960 / BPM`. The four prompts describe distinct parts; LoopMaster Batch creates four seed variations per prompt, giving 16 audio variants per pack.

Each rendered variant has adjacent PCM24 WAV, Ogg Vorbis and JSON files. JSON records the actual prompts, seeds, model settings, requested timing, processing and checksums. The catalog mirrors the four loop prompts and stores optional non-loop sounds separately.

## Audio review

Tempo, pitch, instrument isolation and clean loop joins are requested properties to verify by listening. Matching settings do not make separately generated parts phase-aligned stems. Rendered files remain marked unauditioned until reviewed.
