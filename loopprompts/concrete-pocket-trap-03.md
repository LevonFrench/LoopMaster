# Concrete Pocket Trap 03

## 4 SA3 Loop Prompts

**Shared generation settings:** 140 BPM | 4/4 | 4 bars | 6.857143 seconds | F minor.

Set the duration in the generator as well as using the prompt. Tempo, key, isolation and loop joins are targets to check by listening, not guaranteed output properties. These are independently generated parts, not stems extracted from one performance.

### Prompt 1: Trap drum groove
```text
TrackType: Instrument, 140 BPM, 4/4. Isolated hard-hitting trap drums with a short deep kick, sharp rimshot backbeat and tight closed hats. Brief triplet hat flurries answer the rimshot in a sparse half-time pocket; crunchy attacks. Repeating four-bar loop, steady phrase throughout, clean return to the opening beat.
```

### Prompt 2: Saturated 808 riff
```text
TrackType: Instrument, 140 BPM, 4/4, F minor. Solo 808 bass playing low sustained roots followed by quick octave slides. Clear gaps separate the phrases; rounded sub weight, audible upper harmonics and controlled saturation suit a half-time trap groove. Repeating four-bar loop, steady phrase throughout, clean return to the opening beat.
```

### Prompt 3: Found-sound percussion
```text
TrackType: Instrument, 140 BPM, 4/4. Isolated percussion groove built from wooden taps, papery shuffles and small metallic clicks. Uneven accents form a repeating syncopated pattern around a steady pulse; dry, intimate recording with light grit. Repeating four-bar loop, steady phrase throughout, clean return to the opening beat.
```

### Prompt 4: Muted bell hook
```text
TrackType: Instrument, 140 BPM, 4/4, F minor. Solo muted bell synthesizer playing a sparse trap hook with a low two-note question and a higher answering note. Rounded mallet attacks, short decays and a faint dark delay leave room around the phrase. Repeating four-bar loop, steady phrase throughout, clean return to the opening beat.
```
