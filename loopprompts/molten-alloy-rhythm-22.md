# Molten Alloy Rhythm 22

## 4 SA3 Loop Prompts

**Shared generation settings:** 120 BPM | 4/4 | 4 bars | 8.000000 seconds | E minor.

Set the duration in the generator as well as using the prompt. Tempo, key, isolation and loop joins are targets to check by listening, not guaranteed output properties. These are independently generated parts, not stems extracted from one performance.

Uneven accents repeat against a steady pulse; short gritty attacks and deliberate gaps define the arrangement. Repeating four-bar loop, steady phrase throughout, clean return to the opening beat.

```text
TrackType: Instrument, 120 BPM, 4/4. Isolated industrial percussion groove with muted pipe strikes, scraped-metal taps and low drum pulses. ### Prompt 4: Glassy chord pulse
```
