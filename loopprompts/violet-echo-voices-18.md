# Violet Echo Voices 18

## 4 SA3 Loop Prompts

**Shared generation settings:** 128 BPM | 4/4 | 4 bars | 7.500000 seconds | D minor.

Set the duration in the generator as well as using the prompt. Tempo, key, isolation and loop joins are targets to check by listening, not guaranteed output properties. These are independently generated parts, not stems extracted from one performance.

### Prompt 1: Ornamented wordless melody
```text
TrackType: Instrument, 128 BPM, 4/4, D minor. Solo wordless female voice singing a repeating minor-key melody with fluid slides and small ornamental turns. Open vowel tones, gentle breath detail and short phrase endings, with a restrained dark room tail. Repeating four-bar loop, steady phrase throughout, clean return to the opening beat.
```

### Prompt 2: Vocal chop hook
```text
TrackType: Instrument, 128 BPM, 4/4, D minor. Isolated pitched vocal chops repeating a syncopated minor-key hook. Short open-vowel fragments alternate with lower answering tones; clean edits, clear rests and brief tempo-synced echoes define the rhythm. Repeating four-bar loop, steady phrase throughout, clean return to the opening beat.
```

### Prompt 3: Wordless choir harmony
```text
TrackType: Instrument, 128 BPM, 4/4, D minor. Isolated wordless choir repeating a slow minor chord sequence on rounded vowel tones. Lower held harmonies support a gently moving upper voice; even dynamics and compact hall ambience keep the phrase contained. Repeating four-bar loop, steady phrase throughout, clean return to the opening beat.
```

### Prompt 4: Hummed rhythmic ostinato
```text
TrackType: Instrument, 128 BPM, 4/4, D minor. Solo wordless humming voice repeating a soft, syncopated three-note motif. Closed-mouth tones alternate with short breathy vowel answers, with gentle pitch slides, close detail and a small room tail. Repeating four-bar loop, steady phrase throughout, clean return to the opening beat.
```
