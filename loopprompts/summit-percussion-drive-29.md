# Summit Percussion Drive 29

## 4 SA3 Loop Prompts

**Shared generation settings:** 128 BPM | 4/4 | 4 bars | 7.500000 seconds.

Set the duration in the generator as well as using the prompt. Tempo, key, isolation and loop joins are targets to check by listening, not guaranteed output properties. These are independently generated parts, not stems extracted from one performance.

### Prompt 1: Festival drop drums
```text
TrackType: Instrument, 128 BPM, 4/4. Isolated festival-house drums with a deep four-on-the-floor kick, layered clap backbeat and bright offbeat hats. Short snare pickups add movement; firm attacks and contained drum tails maintain an even driving groove. Repeating four-bar loop, steady phrase throughout, clean return to the opening beat.
```

### Prompt 2: Hand-drum tops
```text
TrackType: Instrument, 128 BPM, 4/4. Isolated percussion groove with alternating bongo strokes, muted djembe slaps and light tambourine accents. Repeating syncopated answers ride a steady pulse; clear hand attacks and short room ambience. Repeating four-bar loop, steady phrase throughout, clean return to the opening beat.
```

### Prompt 3: Snare rhythm loop
```text
TrackType: Instrument, 128 BPM, 4/4. Isolated snare-and-shaker rhythm with repeating sixteenth-note snare taps, stronger backbeat accents and a steady shaker. Small ghost-note variations add movement while the pattern holds a constant intensity and pulse. Repeating four-bar loop, steady phrase throughout, clean return to the opening beat.
```

### Prompt 4: Interlocking tom percussion
```text
TrackType: Instrument, 128 BPM, 4/4. Isolated hand-played tom percussion with low floor-tom anchors and dry high-tom replies. Soft rim clicks mark the spaces between phrases; repeating syncopation, natural dynamic variation and compact room resonance. Repeating four-bar loop, steady phrase throughout, clean return to the opening beat.
```
