# Chrome Motion Textures 05

## 4 SA3 Loop Prompts

**Shared generation settings:** 128 BPM | 4/4 | 4 bars | 7.500000 seconds.

Set the duration in the generator as well as using the prompt. Tempo, key, isolation and loop joins are targets to check by listening, not guaranteed output properties. These are independently generated parts, not stems extracted from one performance.

### Prompt 1: Pulsing noise rhythm
```text
TrackType: Instrument, 128 BPM, 4/4. Solo noise synthesizer playing a repeating festival-house rhythm of short filtered bursts. Bright offbeat swishes alternate with darker sixteenth-note pulses, with fast decays and a consistent filter cycle. Repeating four-bar loop, steady phrase throughout, clean return to the opening beat.
```

### Prompt 2: Rhythmic synth siren
```text
TrackType: Instrument, 128 BPM, 4/4. Solo electronic siren synthesizer repeating a short rising-and-falling pitch figure over a steady house pulse. Staccato gated notes and clipped tempo-synced echoes give the phrase a rhythmic shape. Repeating four-bar loop, steady phrase throughout, clean return to the opening beat.
```

### Prompt 3: Low brass-synth pulse
```text
TrackType: Instrument, 128 BPM, 4/4. Solo low brass synthesizer playing a repeating pattern of short resonant chord pulses. Rounded attacks, gritty midrange and small gaps between accents create steady cinematic tension, with tightly controlled room decay. Repeating four-bar loop, steady phrase throughout, clean return to the opening beat.
```

### Prompt 4: Metallic mallet rhythm
```text
TrackType: Instrument, 128 BPM, 4/4. Solo metallic mallet synthesizer playing a syncopated repeating sequence of tuned chimes. Alternating low and high notes form a compact hook; crisp attacks and short filtered echoes create a percussive shimmer. Repeating four-bar loop, steady phrase throughout, clean return to the opening beat.
```
